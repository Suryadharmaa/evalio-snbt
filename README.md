# Evalio SNBT — Greenfield Codex Cloud Starter Pack

**Not a runnable web app yet.** This kit is the product/engineering contract for building Evalio from scratch in a **new** GitHub repository via Codex Cloud. It intentionally contains no old Evalio code, package-lock, or production credentials.

Read in order:
1. `docs/PRD.md` — full product spec including GitHub skill/library choices.
2. `docs/CODEX_CLOUD.md` — cloud setup, install commands, bootstrap prompt and token-efficient workflow.
3. `docs/TASKS.md` — task board and acceptance tests.
4. `docs/ARCHITECTURE.md` — data model and secure exam engine.
5. `docs/DESIGN.md` — Academic Ambition design tokens and screen behavior.
6. `AGENTS.md` — persistent brief instructions for Codex.
7. `.agents/skills/*/SKILL.md` — four scoped reusable project skills.

**Getting started:** Create new private GitHub repo, upload this kit to its root (including dotfiles), connect the new repo to Codex Cloud, and run the EVAL-000 prompt in `docs/CODEX_CLOUD.md`. Choose GPT-6.1 Sol / Medium if available. No setup on a local laptop is required.

**Important:** Legacy `Suryadharmaa/evalio` remains unchanged. Official SNBT 2027 details must be verified as they are published. All questions are original/licensed and independently reviewed. No production payment or deployment without founder approval.
