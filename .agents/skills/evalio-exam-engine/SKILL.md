# Evalio Exam Engine

Read `docs/ARCHITECTURE.md` and relevant subsections of `docs/PRD.md`, then only files needed for the assigned ticket.

Use versioned exam blueprint and original/reviewed question versions; 2026 is historical and cannot be called official 2027. Server keeps answer keys, deadlines, attempt ownership, option mappings, and final result calculations. `correct + incorrect + blank = total`; no fake official score, passing grade or admission probability. `created → in_progress → submitted/expired/invalidated` atomic state transitions. Submit and autosave idempotent; reject post-expiry changes and cross-user writes. On refresh/reconnect reconcile server-saved state; indicate unsynced state clearly.

Every ticket requires unit tests for scoring and negative integration tests for auth, concurrency, timeout and answer leakage. No giant autogenerated question dump without independent editorial review.
