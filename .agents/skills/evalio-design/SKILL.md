# Academic Ambition — Evalio UI

Read `docs/DESIGN.md` and only affected components. Follow one source of truth for tokens (purple/indigo, warm neutrals, green successes). No generic neon, massive gradients, unlicensed campus logos/photos or fake endorsements.

Prioritize 360px phone, 1280px desktop, keyboard controls, focus visibility, readable KaTeX, accessible labels and Indonesian microcopy. Exam runner must be distraction-free; no interstitial ads, celebration effects or irrelevant animations.

For a visual task: (1) sketch 5-line layout plan; (2) implement one screen with existing primitives; (3) run relevant component checks and Playwright viewport screenshots; (4) report design deviations. Use UI/UX Pro Max for *exploration* only if installed and chosen; Vercel Web Design Guidelines for separate review.
